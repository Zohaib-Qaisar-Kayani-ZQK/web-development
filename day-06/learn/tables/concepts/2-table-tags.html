The Table Tags You Are Learning

HTML Table Elements and Attributes
Element / Attribute Purpose Typical Use
<table> Creates the table Complete table container
<caption> Table title Describes the table
<thead> Groups header rows Column and grouped headings
<tbody> Groups main data rows Actual records
<tfoot> Groups summary rows Totals, averages, summaries
<tr> Creates a row Horizontal table row
<th> Creates a heading cell Column or row heading
<td> Creates a data cell Actual value
colspan One cell spans multiple columns Horizontal grouping
rowspan One cell spans multiple rows Vertical grouping
