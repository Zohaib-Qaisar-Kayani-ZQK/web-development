Table Debugging Guide

Common Table Mistakes
Mistake Problem What To Check
Wrong cell count Columns stop lining up logically. Count logical cells in each row.
Wrong rowspan Following rows become shifted. Count exactly how many rows the cell covers.
Wrong colspan Headings or summaries cover the wrong area. Count exactly how many columns the cell covers.
Repeated grouped category Unnecessary repetition. Consider rowspan.
Missing tfoot Summary is mixed into the main records. Use tfoot for the project when required.
Unclear headers Readers cannot identify columns easily. Use th for headings.
Main debugging rule Draw the logical grid before changing the markup.
