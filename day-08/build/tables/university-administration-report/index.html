Final Master Challenge

Build one large table from scratch without copying any previous example.

University Administration Report

The university needs one structured report covering departments, students, employees, courses, and summary information.

Required

  • Use a caption.
  • Use thead.
  • Use tbody.
  • Use tfoot.
  • Use tr, th, and td.
  • Use rowspan.
  • Use colspan.
  • Include at least three departments.
  • Include at least twelve student records.
  • Include at least six employees.
  • Include at least eight courses.
  • Group related information.
  • Add meaningful summary rows.
Master Challenge Requirements
Concept Required Purpose
table Yes Main container
caption Yes Title
thead Yes Headers
tbody Yes Records
tfoot Yes Summary
tr Yes Rows
th Yes Headings
td Yes Data
rowspan Yes Vertical grouping
colspan Yes Horizontal grouping
Total Concepts 10

Rules

  1. Do not copy the earlier examples.
  2. Do not use CSS.
  3. Do not use JavaScript.
  4. Draw the logical grid first.
  5. Decide the number of logical columns.
  6. Mark every rowspan.
  7. Mark every colspan.
  8. Write the HTML.
  9. Open it in the browser.
  10. Fix every alignment problem yourself.
